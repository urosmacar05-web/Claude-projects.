# Claude-projects.

## Rent a car — sajt

Statički sajt (HTML/CSS/JS, bez build koraka). Otvorite `index.html` ili pokrenite:

```bash
python3 -m http.server 8000
```

- `index.html`, `css/styles.css`, `js/app.js`: sajt (crnogorski + engleski prevod)
- `img/`: optimizovane WebP slike za web
- `assets/`: originalne fotografije i podaci o vozilima
- Vozila, cijene i prevodi se mijenjaju u `js/app.js` (`FLEET` i `I18N`)
